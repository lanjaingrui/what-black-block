# 别踩白块

一个原生微信小程序小游戏，玩法灵感来自经典的“别踩白块”：依次点击当前行唯一的黑块，点击白块或点错行则结束。

## 玩法

- **无尽模式**：持续点击黑块，挑战最高分。
- **计时模式**：在 60 秒内尽可能多地点击黑块。
- **急速模式**：黑块自动向下移动，需要及时点击当前目标。

分数保存在当前设备的本地缓存中，不提供云端排行榜或云端存档。

## 项目结构

```text
.
├── app.js                    # 应用级状态和本地最高分读取
├── app.json                  # 页面路由和全局窗口配置
├── app.wxss                  # 全局样式
├── project.config.json       # 小程序导入配置
├── sitemap.json              # 页面收录规则
├── pages/
│   ├── index/                # 模式选择首页
│   ├── endless/              # 无尽模式
│   ├── time/                 # 计时模式
│   ├── speed/                # 急速模式
│   └── end/                  # 结算页
└── LICENSE                   # MIT 许可证及原作者信息
```

项目使用原生 WXML、WXSS、JavaScript 和 JSON；没有 npm 依赖或构建步骤。`project.config.json` 当前使用 `touristappid` 占位值，不能用于正式发布。获得本小程序可用的 AppID 后再替换；不要复用 `beat-the-pig` 项目的 AppID。

`.vscode/mcp.json` 是开发者本机专用配置，含本机绝对路径，不纳入公开仓库；`docs/superpowers/` 是本地设计和执行记录，也不纳入公开仓库。

## 本地导入与试玩

1. 将本项目根目录作为小程序项目导入，项目根目录中应能看到 `project.config.json`。
2. 使用有权访问该小程序 AppID 的开发者账号；占位 AppID 仅用于配置示例。
3. 编译项目并进入首页，分别打开无尽、计时和急速模式，检查点击、计分、结束和本机最高分。
4. 如果要配置微信开发者工具 MCP，请在本机创建项目级 `.vscode/mcp.json` 并填入自己的项目路径和 CLI 路径；不要将包含个人本机路径的配置提交到公开仓库。尚未通过 MCP 或模拟器验证本项目。

## 上传与发布流程

替换为获批的 AppID 并完成代码自测后，再按小程序后台的当前流程上传代码、设为体验版、由体验成员验证、提交审核，最后由项目所有者确认发布。提交审核和发布都是需要人工确认的操作；本项目不会自动执行。

## 隐私状态

阶段 2 的目标声明是：“本小程序不采集任何用户个人信息、不发起任何网络请求。”**这不是当前代码的合规结论**：现有 `app.js` 仍保留旧版 `wx.login` 和 `wx.getUserInfo` 调用，须在阶段 2 删除并复核后，才能按该目标描述项目。当前阶段不要据此提交隐私声明或审核。
